# Privacy Policy — Jarvis for Windows

Effective date: November 8, 2026. Intended publisher: STARS LLC / Sovereign Technical and Research Solutions.

Jarvis for Windows is a local desktop frontend to a privately operated Jarvis AI server. It has no ad or analytics SDK. It does not automatically transmit conversations, device data or contacts to the frontend publisher. It communicates directly with the selected local Jarvis instance or, when chosen by the user, an authorized remote Jarvis instance on the user's separate Tailscale network over encrypted HTTPS.

The private Jarvis backend may store chats, task history and memory under the server owner's chosen policy; those records are not contained in this frontend. Tailscale is a separate network service with its own account/data practices.

The user controls which server to connect to and can delete the frontend executable. Deleting the frontend does not delete memory retained on the private server.

Publication contact details must be verified before issuing a general production installer. This policy covers the Windows frontend only.
